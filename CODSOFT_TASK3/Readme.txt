Description:
A console-based ATM simulation built in Java using object-oriented design. The system separates account logic from the user interface: a BankAccount class manages the balance, and an ATM class handles the menu and user interaction. Users can withdraw, deposit and check their balance, and the program validates every input to handle invalid amounts, insufficient funds and non-numeric entries without crashing.

Key features:

Withdraw, deposit and balance check
Rejects zero/negative amounts and overdrafts
Handles invalid menu and amount input

Tech: Java, OOP (encapsulation, separation of concerns), Scanner
