Description:
A GUI-based quiz application built in Java Swing that tests core Java concepts through 10 multiple-choice questions. Each question has a 15-second countdown that turns red in the final 5 seconds and auto-submits when time runs out. At the end, the app shows the score, the percentage, and a question-by-question review of correct, wrong and unanswered questions.

Key features:

15-second timer per question using javax.swing.Timer
Auto-submit on timeout; warns if Submit is clicked with no option selected
Results summary with score, percentage and answer review

Tech: Java, Swing (JFrame, JRadioButton, ButtonGroup, Timer), event-driven programming
